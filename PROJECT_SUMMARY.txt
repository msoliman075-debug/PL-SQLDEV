================================================================================

PROJECT OVERVIEW
================================================================================
A complete, production-ready dynamic authorization system for Oracle APEX that
provides flexible, role-based access control for Pages, Menus, Regions, and
Buttons with end-user administration capabilities.

INSTALLATION INSTRUCTIONS
================================================================================

Method 1: Quick Install (Recommended)
--------------------------------------
1. Connect to your Oracle database as appropriate schema owner
2. Execute: @00_Quick_Start_Install.sql
3. Follow prompts and review output
4. All components will be installed automatically

Method 2: Manual Install
------------------------
1. Execute scripts in order:
   - @01_DDL_Authorization_Tables.sql
   - @02_PKG_SPEC_Authorization.sql
   - @03_PKG_BODY_Authorization.sql
   - @04_Sample_Data_and_Tests.sql (optional)
   - @06_Utility_Views.sql (optional)

2. Verify installation:
   SELECT object_name, object_type, status 
   FROM user_objects 
   WHERE object_name LIKE 'APEX_AUTH%';

3. Initialize system:
   BEGIN
       apex_authorization_pkg.initialize_default_permissions;
   END;
   /

APEX CONFIGURATION STEPS
================================================================================

1. Create Authorization Scheme:
   - Shared Components > Security > Authorization Schemes
   - Name: Dynamic Authorization - Pages
   - Type: PL/SQL Function Returning Boolean
   - Function:
     RETURN apex_authorization_pkg.is_page_authorized(
         p_page_id => :APP_PAGE_ID,
         p_application_id => :APP_ID,
         p_username => :APP_USER
     );

2. Apply to Page:
   - Page Properties > Security > Authorization Scheme
   - Select: Dynamic Authorization - Pages
   - Page Properties > Advanced > Static ID: PAGE_<number>

3. Register Page in System:
   BEGIN
       apex_authorization_pkg.register_object(
           p_application_id => 100,
           p_object_type => 'PAGE',
           p_object_code => 'PAGE_10',
           p_object_name => 'Dashboard',
           p_page_id => 10
       );
   END;
   /

4. Grant Access:
   BEGIN
       apex_authorization_pkg.grant_permission(
           p_role_code => 'USER',
           p_application_id => 100,
           p_object_code => 'PAGE_10',
           p_permission_code => 'VIEW'
       );
   END;
   /

COMMON USE CASES
================================================================================

1. Time-Limited Access:
   BEGIN
       apex_authorization_pkg.assign_role_to_user(
           p_username => 'CONTRACTOR',
           p_role_code => 'TEMP_ACCESS',
           p_effective_from => SYSDATE,
           p_effective_to => SYSDATE + 90
       );
   END;
   /

2. Special User Access:
   BEGIN
       apex_authorization_pkg.grant_user_permission(
           p_username => 'AUDITOR',
           p_application_id => 100,
           p_object_code => 'FINANCIAL_DATA',
           p_permission_code => 'VIEW',
           p_is_granted => 'Y',
           p_override_roles => 'Y'
       );
   END;
   /

3. Lock User Account:
   BEGIN
       apex_authorization_pkg.update_user(
           p_username => 'SUSPENDED.USER',
           p_is_locked => 'Y'
       );
   END;
   /

4. Check Multiple Roles:
   IF apex_authorization_pkg.has_any_role(
       p_username => :APP_USER,
       p_role_codes => 'ADMIN,MANAGER,SUPERVISOR'
   ) THEN
       -- User has administrative privileges
   END IF;

TROUBLESHOOTING
================================================================================

Problem: Authorization always fails
Solution: 
   - Check if user exists and is active
   - Verify role assignments
   - Confirm object is registered
   - Check permissions are granted
   - Query: SELECT * FROM apex_auth_v_user_permissions WHERE username = 'USER'

Problem: Changes not taking effect
Solution:
   - Clear cache: apex_authorization_pkg.clear_cache;
   - Logout/login to restart APEX session

Problem: Package won't compile
Solution:
   - Check dependencies (APEX must be installed)
   - Review errors: SELECT * FROM user_errors WHERE name = 'APEX_AUTHORIZATION_PKG'

Problem: Audit log not working
Solution:
   - Enable: apex_authorization_pkg.set_config('ENABLE_AUDIT_LOG', 'Y')
   - Check autonomous transaction privileges
