QUICK START - GET RUNNING IN 5 MINUTES
================================================================================

STEP 1: Install the System
---------------------------
Connect to your Oracle database and run:

    SQL> @00_Quick_Start_Install.sql

This will:
- Create all 9 authorization tables
- Create the authorization package (spec + body)
- Initialize default roles and permissions
- Create sample users (APEX_ADMIN, DEMO_USER)
- Register sample objects for testing
- Run validation tests
- Display summary report

STEP 2: Create APEX Authorization Scheme
-----------------------------------------
In your APEX application:
1. Go to: Shared Components > Security > Authorization Schemes
2. Click: Create
3. Set:
   - Name: Dynamic Authorization - Pages
   - Type: PL/SQL Function Returning Boolean
   - Function:
     
     RETURN apex_authorization_pkg.is_page_authorized(
         p_page_id => :APP_PAGE_ID,
         p_application_id => :APP_ID,
         p_username => :APP_USER
     );

4. Click: Create Authorization Scheme

STEP 3: Apply to Your Pages
----------------------------
For each page you want to secure:
1. Open page in Page Designer
2. Set page Static ID to: PAGE_<number> (e.g., PAGE_10)
3. Apply Authorization Scheme: Dynamic Authorization - Pages
4. Register page and grant permissions (see examples below)

STEP 4: Register Objects and Grant Access
------------------------------------------
Register your APEX page:

    BEGIN
        apex_authorization_pkg.register_object(
            p_application_id => 100,  -- Your app ID
            p_object_type => 'PAGE',
            p_object_code => 'PAGE_10',
            p_object_name => 'Dashboard',
            p_page_id => 10
        );
    END;
    /

Grant access to a role:

    BEGIN
        apex_authorization_pkg.grant_permission(
            p_role_code => 'USER',
            p_application_id => 100,
            p_object_code => 'PAGE_10',
            p_permission_code => 'VIEW'
        );
    END;
    /

STEP 5: Create Users and Assign Roles
--------------------------------------
Create an actual user:

    BEGIN
        apex_authorization_pkg.create_user(
            p_username => 'JOHN.DOE',
            p_email => 'john.doe@company.com',
            p_full_name => 'John Doe'
        );
        
        apex_authorization_pkg.assign_role_to_user(
            p_username => 'JOHN.DOE',
            p_role_code => 'USER'
        );
    END;
    /

DONE! Your authorization system is now active!

COMMON USAGE EXAMPLES
================================================================================

EXAMPLE 1: Secure a Region
---------------------------
In Page Designer, set Region Server-side Condition:

    RETURN apex_authorization_pkg.is_region_authorized(
        p_region_code => 'FINANCIAL_DATA',
        p_application_id => :APP_ID,
        p_username => :APP_USER
    );

Then register and grant:

    BEGIN
        apex_authorization_pkg.register_object(
            p_application_id => 100,
            p_object_type => 'REGION',
            p_object_code => 'FINANCIAL_DATA',
            p_object_name => 'Financial Data Region',
            p_page_id => 20
        );
        
        apex_authorization_pkg.grant_permission(
            p_role_code => 'MANAGER',
            p_application_id => 100,
            p_object_code => 'FINANCIAL_DATA',
            p_permission_code => 'VIEW'
        );
    END;
    /

EXAMPLE 2: Secure a Button
---------------------------
In Page Designer, set Button Server-side Condition:

    RETURN apex_authorization_pkg.is_button_authorized(
        p_button_code => 'BTN_DELETE',
        p_application_id => :APP_ID,
        p_username => :APP_USER
    );

EXAMPLE 3: Check User Roles
----------------------------
In PL/SQL or APEX conditions:

    IF apex_authorization_pkg.has_role(:APP_USER, 'ADMIN') THEN
        -- User is admin
    END IF;

    IF apex_authorization_pkg.has_any_role(:APP_USER, 'ADMIN,MANAGER') THEN
        -- User has administrative privileges
    END IF;

EXAMPLE 4: Grant Temporary Access
----------------------------------
Give user access for 90 days:

    BEGIN
        apex_authorization_pkg.assign_role_to_user(
            p_username => 'CONTRACTOR',
            p_role_code => 'TEMP_USER',
            p_effective_from => SYSDATE,
            p_effective_to => SYSDATE + 90
        );
    END;
    /

EXAMPLE 5: User-Specific Override
----------------------------------
Give one user special access:

    BEGIN
        apex_authorization_pkg.grant_user_permission(
            p_username => 'SPECIAL.USER',
            p_application_id => 100,
            p_object_code => 'ADMIN_PAGE',
            p_permission_code => 'VIEW',
            p_is_granted => 'Y',
            p_override_roles => 'Y'
        );
    END;
    /

Monitor Recent Access Denials:

    SELECT * FROM apex_auth_v_recent_denials;

Check Expiring Access:

    SELECT * FROM apex_auth_v_expiring_roles
    WHERE expiration_status = 'EXPIRES THIS WEEK';

View Audit Trail:

    SELECT * FROM apex_auth_audit_log
    WHERE username = 'JOHN.DOE'
    AND audit_timestamp > SYSDATE - 7
    ORDER BY audit_timestamp DESC;

TROUBLESHOOTING QUICK REFERENCE
================================================================================

Problem: Authorization always fails
Solution: 
  1. Check user exists: SELECT * FROM apex_auth_users WHERE username = 'USER'
  2. Check roles assigned: SELECT * FROM apex_auth_v_user_roles WHERE username = 'USER'
  3. Check object registered: SELECT * FROM apex_auth_objects WHERE object_code = 'PAGE_10'
  4. Check permissions granted: SELECT * FROM apex_auth_v_role_permissions WHERE object_code = 'PAGE_10'

Problem: Changes not taking effect
Solution: Clear cache with apex_authorization_pkg.clear_cache;

Problem: Package won't compile
Solution: Check user_errors view for details

Problem: Audit log not populating
Solution: Enable with apex_authorization_pkg.set_config('ENABLE_AUDIT_LOG', 'Y')
