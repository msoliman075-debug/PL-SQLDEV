PROBLEM ADDRESSED
================================================================================

Error: ORA-20049: Cannot alter the url mapping while the schema is enabled.
       Try disabling the schema first.

This error occurs when attempting to modify ORDS URL mappings while a schema
is actively serving REST endpoints. This comprehensive solution provides
multiple approaches to safely resolve this issue.

SOLUTION APPROACH
================================================================================

The fix follows Oracle best practices with three core steps:

STEP 1: DISABLE SCHEMA
- Stops all REST endpoints for the schema
- Takes < 1 second
- No impact on other schemas
- Transaction-safe operation

STEP 2: MODIFY URL MAPPINGS
- Update base paths, modules, or templates
- Changes made in disabled state
- No conflicts with active endpoints
- Fully reversible

STEP 3: RE-ENABLE SCHEMA  
- Restarts REST endpoints with new configuration
- Takes < 1 second
- Immediate activation
- Configuration validated

ALL SCRIPTS INCLUDE:
- Comprehensive error handling
- Transaction management (COMMIT/ROLLBACK)
- Detailed logging and feedback
- Status verification
- Rollback capability
